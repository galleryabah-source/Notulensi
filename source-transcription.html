🎙️ Source Transcription Engine

Ambil audio digital dari Zoom/meeting atau tab YouTube, atau upload audio/video, lalu kirim ke server transcription engine.

🎧 Capture

Saat browser meminta pemilihan sumber, pilih window/tab yang benar dan aktifkan Share audio / Bagikan audio. Volume speaker perangkat tidak digunakan sebagai sumber audio.

Siap.

📁 Upload

File dikirim ke server transcription engine. Untuk production panjang, gunakan capture/chunk atau file yang ukurannya sesuai batas endpoint.

📝 Hasil Transkripsi

Alur

Zoom / YouTube / Upload → Source Transcription Engine → Server AI → Transcript → Meeting Intelligence → Ringkasan, keputusan, action items, dan laporan.
