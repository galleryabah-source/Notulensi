## Governance

Each phase follows:

IMPLEMENT → TEST → AUDIT → REGRESSION → EVIDENCE → GO/NO-GO

A passing static contract is not runtime evidence. Critical failures remain fail-closed. Legacy data/code is retained until explicit migration evidence exists.
