# IMIGRASI 24 — Roadmap

**Baseline:** 0.1.0 — 2026-08-27
**Rule:** roadmap evolves through validated brainstorming and implementation evidence.

## Phase 0 — Governance & Discovery
- Service catalog and journey mapping
- Passport and WNA knowledge inventory
- Regulation/legal-source inventory
- Data classification and privacy model
- WhatsApp Business architecture and compliance requirements
- Security, audit, SLA, and escalation design
- Knowledge governance and approval workflow

## Phase 1 — MVP
- Official WhatsApp message gateway
- Intent detection for core passport/WNA/service intents
- Official Answer Database
- Rule/policy engine
- Response templates
- Admin knowledge editor
- Human handoff
- Complaint/ticket intake
- Audit trail
- Basic analytics
- ID/EN language support
- Graceful AI-off operation

## Phase 2 — Intelligent Service
- Hybrid lexical + semantic retrieval
- RAG
- Conversation context
- AI provider abstraction/router
- Multi-provider fallback
- Voice message transcription
- Document classification
- Office intelligence
- Improved complaint routing
- Knowledge-gap mining

## Phase 3 — Transactional Service
- Passport/request status integrations where officially supported
- Appointment integrations where officially supported
- Ticket status
- Notifications
- Service availability/disruption information
- Stronger authentication for personal/status lookups

## Year 2 — Immigration Intelligence
- Knowledge graph
- Advanced service analytics
- Cross-office analytics
- WNA conversational assistant
- More languages
- Automated knowledge freshness checks
- AI-assisted knowledge compilation with human approval

## Year 3 — National Conversational Core
- Channel-agnostic conversation API
- Web/mobile/kiosk/voice channels
- Shared identity/context where legally permitted
- Central service catalog
- Reusable agency integration contracts

## Year 4 — AI-Assisted Operations
- Conversation summaries
- Suggested responses
- Ticket classification/routing
- Duplicate case detection
- Operational anomaly detection
- Supervisor intelligence dashboards

## Year 5 — Digital Service Intelligence
- Demand forecasting
- Emerging-question detection
- Regulation-impact analysis
- Service-quality intelligence
- Continuous knowledge governance
- Provider/model replacement with no core rewrite

## Resilience Track — Continuous
- AI-off mode tests
- Provider outage drills
- Queue/retry/idempotency tests
- Backup/restore tests
- Disaster recovery tests
- Security regression tests
- Knowledge rollback/version tests
- Human escalation tests

## Priority Order
1. Reliability and governance
2. Official knowledge and answer database
3. Core WhatsApp conversation service
4. Human handoff and complaints
5. AI/RAG augmentation
6. Official transactional integrations
7. Advanced intelligence

## Success Definition
The platform must remain useful when AI is disabled. AI increases coverage and conversational quality but is not a single point of failure.
